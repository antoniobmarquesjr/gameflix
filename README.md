# Gameflix

Protótipo acadêmico de um catálogo de **filmes e jogos**, desenvolvido como atividade da disciplina de Front-End.

## Sobre o projeto

O Gameflix apresenta uma interface para explorar títulos e conhecer diferentes gêneros de filmes e jogos. O projeto foi criado com foco na estruturação de páginas web, na estilização visual e na responsividade.

## Tecnologias

- HTML5
- CSS3
- Flexbox, Grid e media queries

## Páginas

- **Início (`index.html`)**: destaques e catálogo inicial.
- **Login (`LoginGameflix.html`)**: formulário demonstrativo de entrada.
- **Cadastro (`CadastroGameflix.html`)**: formulário demonstrativo de registro.
- **Preferências (`Preferencia.html`)**: navegação por gêneros e títulos.

## Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` no navegador.

Não é necessário instalar dependências ou configurar um servidor.

## Publicação pelo GitHub Pages

Em um repositório público, acesse **Settings → Pages**, selecione **Deploy from a branch**, escolha a branch `main` e a pasta `/ (root)`. Após salvar, o GitHub exibirá o endereço do site quando a publicação estiver concluída.

## Limitações

Este projeto é uma **demonstração visual**:

- Não há backend, banco de dados ou autenticação real.
- Os formulários não criam contas e não validam credenciais.
- O catálogo é estático e não reproduz conteúdo.
- Parte dos pôsteres é carregada por URLs externas, que podem deixar de funcionar.

**Não insira informações pessoais reais nos formulários.**

## Créditos e uso de imagens

Projeto realizado como atividade acadêmica.

As capas, marcas e demais elementos relacionados a filmes e jogos pertencem a seus respectivos titulares e são utilizados apenas como referência visual e didática. Este projeto não possui vínculo com as empresas responsáveis por esses títulos.
